# 🎬 Netflix Clone (MERN Stack)

A fully responsive Netflix-inspired web application built using the MERN stack with advanced UI/UX features like inline trailer playback, dynamic hero banner, and smooth animations.

---

## 🚀 Features

* 🔐 Email-based login authentication
* 🎥 Inline trailer playback (no popup)
* 🖼️ Dynamic Hero Banner (Hotstar-style)
* ⚡ Smooth animations and transitions
* 🎯 Movie categories (Trending, Top Rated, Action, Comedy)
* 🔎 Search functionality
* ❤️ Clean and modern UI

---

## 🛠️ Tech Stack

* Frontend: React.js, CSS
* Backend: Node.js, Express.js
* Database: MongoDB
* API: TMDB

---

## ⚙️ Installation

```bash
git clone https://github.com/lalit2406/Netflix-Clone.git
cd Netflix-Clone
npm install
npm run dev
```

---

## 🌐 Environment Variables

Create a `.env` file:

```
VITE_TMDB_API_KEY=your_api_key_here
```
